## Three beginner workflows

### 1. Local AI assistant without cloud API charges

1. Install Ollama from its [official website](https://ollama.com/).
2. Check the available RAM and select a model that fits.
3. Test with a short prompt and review the output before trusting it.
4. If you want a browser UI, explore Open WebUI and check its setup instructions.

You may still pay for electricity, hardware, or optional cloud services.

### 2. Reproducible creative workflows

1. Read [ComfyUI's official installation guide](https://github.com/Comfy-Org/ComfyUI).
2. Keep a known-good workflow export.
3. Save model version, prompt, seed where relevant, and any dependencies.
4. Test before installing third-party community nodes.

### 3. Learn before automating customer-facing actions

1. Build an AI workflow in [Dify](https://github.com/langgenius/dify).
2. Test with synthetic data instead of private customer information.
3. Review false positives and unsafe outputs.
4. Require human approval for irreversible actions.

## Free versus paid: the questions that matter

- Is the tool free to run locally?
- Are third-party model weights under a separate license?
- Will a connected AI API charge usage fees?
- Do you need GPU hosting or paid storage?
- Is commercial use allowed under all applicable licenses?
